# GoRandomNick
> GoRandomNick generates random nicknames without following a specific theme.

## How to install
1. Open the terminal in the root folder (likely GoRandomNick)
2. Run the following command to compile the program:
    ```bash
    make build
    ```
3. Run this command to install the program (it will ask for your password for the installation):
    ```bash
    sudo make install
    ```
4. Use the following command to verify that it has been installed:
    ```bash
    grn --version
    ```
